# Muay Boran — instaladores

Este repositório guarda apenas os instaladores do aplicativo Windows do Muay Boran (sem código-fonte).

- **Baixar a versão mais recente:** [Muay-Boran-Setup-x64.exe](https://github.com/aslinsjr/muay-boran-releases/releases/latest/download/Muay-Boran-Setup-x64.exe)
- **Jogar no navegador:** https://muayboran.vercel.app

O aplicativo instalado se atualiza sozinho a partir das [releases](https://github.com/aslinsjr/muay-boran-releases/releases).
